# Smart animal husbandry review

This review organises the data, applications, techniques, challenges and opportunities involved in technology-assisted animal husbandry. It connects sensing, machine learning and animal measures with practical livestock-management questions.

## Plain-language summary

Modern livestock systems can combine images, sensors and farm records to observe animal morphology, physiology, behaviour and environment. The review maps these data sources to applications and explains the technical and practical barriers that still limit adoption.

## Review scope

- Animal measures and livestock data
- Machine learning and sensing applications
- Monitoring, management and welfare-related use cases
- Data quality, infrastructure and deployment challenges
- Research opportunities for more reliable and practical systems

## Limits and future work

A review synthesises published evidence; it does not independently validate every cited system or establish that a technology is ready for operational welfare decisions. Readers should check the underlying studies, datasets and validation settings. Future reviews can use preregistered search protocols, formal quality assessment and regularly updated evidence maps.
