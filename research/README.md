## Integrity and open-access policy

- Use the canonical DOI or publisher record and identical title/author metadata.
- Link publisher-hosted full text or an established repository copy; do not upload a publisher PDF unless its licence permits redistribution.
- Distinguish study-specific releases from general datasets and upstream implementations.
- Do not claim that a later application reproduces or validates a paper unless that relationship has been demonstrated.
- Add accepted manuscripts only after confirming the permitted version, embargo and repository conditions.
- Keep limitations beside reported results.

## Using and citing the resources

Read the paper for the published method and evaluation. Each page provides a BibTeX file and identifies whether public data, code, media or an open-access copy is actually available. Citation counts are intentionally not treated as permanent metadata.
